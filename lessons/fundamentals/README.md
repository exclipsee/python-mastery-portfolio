# Lesson 1: Python fundamentals

Start here if it has been a while since you used Python. These exercises use
strings, numbers, booleans, lists, and simple functions.

## Try these

Open `practice.py` and, before reading the implementations, try to write a
function that:

1. Greets a person by name.
2. Tells you whether a whole number is even.
3. Counts the vowels in a piece of text.
4. Adds up a list of prices.

The functions are filled in so the tests pass. Treat them as examples to study,
rewrite, and experiment with. Try a few inputs of your own, then run the tests:

```bash
python3 -m unittest discover -v
```

## Check your understanding

- What is the difference between a string, an integer, and a float?
- What does `%` do in `is_even`?
- Why does `count_vowels` use `.lower()`?
- What should `calculate_total` return for an empty list?

Write a short note in your own words when you can answer these. Move on when
you feel comfortable, not when you can memorize the code.
